# Práctica de Git y GitHub

Repositorio destinado a la práctica de los flujos de trabajo básicos con Git y control de versiones colaborativo.

---

## 🎯 Objetivos

- Inicializar repositorios y gestionar el historial de cambios (`commit`, `log`).
- Crear, fusionar y eliminar ramas locales y remotas (`branch`, `checkout`/`switch`, `merge`).
- Resolver conflictos de integración de código.
- Trabajar con repositorios remotos en GitHub (`fetch`, `pull`, `push`, `PR`).
